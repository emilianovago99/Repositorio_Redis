Detalle de Roles y Servicios

🖥️ Servidor de Gestión (mgmt-node)

IP: 10.0.0.100

  • HAProxy: Balanceador de carga. Detecta al maestro vivo mediante TCP Health Checks y enruta las escrituras.
  • Prometheus & Grafana: Stack de observabilidad en contenedores. Recolecta métricas cada 10s.

👑 Nodo Primario (db-node1)

IP: 10.0.0.129

  • Redis-Server: Rol Master. Procesa el 100% de las escrituras.
  • Redis-Sentinel: Actúa como árbitro (1 de 3 votos) para vigilar la salud del clúster.
  • Cron Jobs: Ejecuta los scripts automatizados de respaldos (PITR) y mantenimiento nocturno.

🛡️ Nodos Secundarios (db-node2/3)

IPs: 10.0.0.204 / 10.0.0.248

  • Redis-Server: Rol Réplica (Read-Only). Mantiene una copia exacta asíncrona de los datos.
  • Redis-Sentinel: Proveen los votos necesarios (Quórum) para realizar un failover automático.
  • Redis_Exporter: Expone las métricas del nodo para Grafana.

📦 OCI Object Storage

  • Bucket: `redis-backups`
  • Almacenamiento seguro fuera de la instancia. Guarda archivos RDB y AOF comprimidos para recuperación ante desastres (DRP).
